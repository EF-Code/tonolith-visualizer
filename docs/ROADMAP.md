# Roadmap

## Near term

- keep the local emulator surface deterministic and easy to inspect;
- add richer instruction and memory explanations;
- preserve keyboard and narrow-screen usability;
- keep build, bundle, and credential checks in CI.

## Later

- add a clearly separated read-only testnet evidence view;
- show contract commitments and transaction finality with source links;
- add keeper and stale-state observations only after real testnet proof exists.

Wallet signing and transaction submission are outside the current roadmap until
there is a separate threat model and product decision.
