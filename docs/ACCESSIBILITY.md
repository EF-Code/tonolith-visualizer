# Accessibility behavior

The lab exposes named buttons, a labeled pace control, live execution status,
live output events, focus-visible outlines, and a minimum layout width of 320px.

Keyboard behavior:

- Space steps once when focus is not on a form control or button.
- Native button activation remains available when a button has focus.
- The pace range input remains usable with standard keyboard controls.

The visual state is not color-only: labels, values, and text statuses accompany
the colored indicators.
